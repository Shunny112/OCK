# 合同会社 O.C.K コーポレートサイト

大分県大分市の合同会社O.C.K（厨房業務委託／完全調理済食材提供）のWebサイト。
デザインは **ajinomoto.co.jp** の実CSSを参照して構造・レイアウト言語を移植し、
配色をクライアント指定のブランドレッド `#E32F1C` に置き換えている。

サイトの立ち位置は「給食会社」ではなく、
**「採用できない・人件費が上がる・厨房が回らない」という施設経営者の経営課題を解決する会社**。
トップの構成もこの順序（経営課題 → 解決の設計 → 数字 → 品質 → 事例 → 導入）に合わせている。

## 参照元のデザイン言語（ajinomoto.co.jp）

トップページのHTMLと `app-files/css/custom/home.css` を取得し、実際の値を移植している。

| 味の素の実装 | O.C.Kでの対応 |
|---|---|
| `html{font-size:62.5%}` の rem グリッド | 同じ（1rem = 10px） |
| `.inner` max-width 1200px | 同じ |
| ヘッダーの罫線セル構成（ロゴ枠／ピル列＋ナビ列／右端ボタン枠） | 同じ。上段=ピル、下段=赤シェブロン付きナビ |
| `.common_btn a`（輪郭ピル＋赤シェブロン `:after`、hoverで赤ベタ反転） | 値までそのまま移植 |
| `#mainv`（白メッセージカード + `.banner` 横並び、背後に手描き風SVG線） | 同構成。線は `stroke-dashoffset` で描画 |
| `.asv h3 span.cover:before`（白幕が右へ抜けて文字が現れる） | `.cover` として実装。1行ずつ遅延 |
| `.important_notices`（`#ffefee` 帯・赤見出し・dl） | 同じ（`--red-pale`） |
| `.newsroom .news-list`（日付＋赤カテゴリ＋枠線ジャンル＋細字タイトル） | 同じ |
| `.link_area:before`（グレー面の上辺に白い三角ノッチ） | 同じ |
| `.future` / `.link_area` のカード（`box-shadow:.1em .1em .3em .1em rgba(0,0,0,.1)` / `border-radius:.5em` / 右下に赤シェブロン） | `.card` として共通化 |
| アクセント `#e60012` | `#E32F1C`（クライアント指定） |

外部ライブラリ依存なし（Google Fonts の Noto Sans JP のみ）。Swiper も jQuery も使っていない。

## アニメーション

| 対象 | 動き |
|---|---|
| MV読み込み | 赤いSVG曲線を描画（2.2s）→ バナーが右から左へワイプ（`clip-path`）→ カード内が4段階で下からせり上がる |
| MV切り替え | 前スライドをフェードアウトしつつ、新バナーをワイプ、カードを赤い面が横切って中身が現れる |
| セクション見出し | 赤い縦バーが上から伸びる → 日本語見出しがマスクからせり上がる |
| 考え方ステートメント | 白幕が右へ抜けて文字が現れる（行ごとに0.52s遅延）。同時に文自体がスクロールで微量ドリフト |
| 18h → 10h 図 | 左右から寄って、赤い三角がバウンドで出現。数字は0からカウントアップ |
| 削減パネル | わずかに拡大しながら着地 |
| カード群 | 交互に遅延（`data-stagger`）してフェードアップ。hoverで浮上＋画像ズーム |
| ギャラリー | `clip-path` で左から開く |
| 食事帯 | 無限マーキー（hoverで停止） |
| ページ最上部 | スクロール進捗の赤いバー |

`prefers-reduced-motion: reduce` で全て無効化される。

## 採用情報ページについて

パンフレット・提供資料に採用条件の記載がないため、`recruit.html` の募集要項は
**実際の条件を確認したうえで差し替える前提**で作成している。
数値（時給・月給・年間休日・勤務時間の具体値）は捏造せず、
「ご経験・保有資格を考慮のうえ決定します」等の表現に留めてある。

公開前に O.C.K 側へ確認が必要な項目：

| 項目 | 現在の記載 | 確認内容 |
|---|---|---|
| 募集職種 | 調理スタッフ／盛付・提供スタッフ／管理栄養士・栄養士の3職種 | 実際に募集している職種・雇用形態 |
| 給与 | 「面談時にご説明します」 | 時給・月給の実額を掲載するか |
| 勤務時間・休日 | 「シフト制（実働8時間程度）」等 | 実際のシフトパターン・年間休日数 |
| 待遇 | 社会保険／交通費／制服貸与／まかない／資格取得サポート | 実際に用意している制度（まかない・資格支援の有無） |
| 応募資格 | 学歴不問・未経験可 | 普通自動車免許の要否など |
| 1日の流れ | セントラルキッチン調理スタッフの一例 | 実際の勤務時間帯・工程 |

※「先輩社員の声」は実在しないコメントの創作になるため設けず、
代わりに「こんな方を歓迎します」を掲載している。実際の社員コメントを
取得できた場合は `.voice` コンポーネント（`case.html` で使用）で追加できる。
